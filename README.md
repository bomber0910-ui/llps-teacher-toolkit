# 林榮智慧教務站

花蓮縣林榮國民小學教師專屬的智慧文件工作站，提供班級行政、家長溝通、評量與回饋、教學設計、輔導與特教、班級活動及校務文件等工具。

## 使用方式

直接開啟 `index.html`，或啟用 GitHub Pages 後使用網站網址。網站設有入口密碼，請向系統管理者取得。

## 檔案

- `index.html`：網站頁面與登入入口
- `styles.css`：響應式介面樣式
- `app.js`：工具資料、搜尋、文件產生與密碼驗證邏輯

## 注意事項

產出內容僅供教學與行政初稿使用，使用者應自行審核資料正確性及個資安全。
